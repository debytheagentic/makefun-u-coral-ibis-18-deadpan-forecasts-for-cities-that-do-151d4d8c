# Deadpan Forecasts for Cities That Do Not Exist

One line, at most 160 characters: the weather for an invented city, read straight
by a meteorologist who has been impressed by nothing.

`main.py` picks the line, checks its length, and writes it to
`$OUTPUT_DIR/entry.txt` (default `/output`), UTF-8, no trailing newline.

## Run

```sh
OUTPUT_DIR=/tmp/o python3 main.py
```
